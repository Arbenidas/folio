# Icono de Apuntes

`markdown-icon.png` es el original de la propuesta 2 (Markdown), seleccionada por el usuario. Fue generado con la herramienta integrada de imágenes; conserva el fondo transparente.

Las versiones para macOS están en `macos/Runner/Assets.xcassets/AppIcon.appiconset/`, en tamaños de 16 a 1024 píxeles. Se generaron con `sips`, conservando el diseño y la transparencia.

## Prompt de la imagen original

Use case: logo-brand. Create a polished standalone macOS desktop app icon concept for Apuntes, a simple personal Markdown note editor for learning. One centered rounded-square icon with generous transparent exterior margin. Concept: warm off-white rounded-square tile, a simple slightly raised paper sheet with one softly folded corner, featuring a single bold dark slate-blue # glyph and two tiny understated horizontal lines below. Restrained and elegant Markdown notes identity, subtle tactile paper depth, large clear silhouette recognizable at 32px. Straight-on view, no perspective scene. Only this icon, no words, no captions, no watermark, no surrounding props. Premium native desktop icon styling.
