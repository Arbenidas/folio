# Registro de cambios

Los cambios destacados de cada versión se documentan aquí.

## [0.1.0-alpha.2] - 2026-11-06

- Añade comprobación de actualizaciones automáticas para macOS con Sparkle.
- Publica paquetes de actualización y notas de versión desde GitHub Actions.

## [0.1.0-alpha.1] - Sin publicar

Primera versión alfa prevista para pruebas públicas.

- Editor local de notas Markdown para macOS.
- Temas Claro, Oscuro, Sepia, Bosque y Gruvbox.
- Selección de carpeta para guardar notas.
- Importación y exportación de archivos Markdown y texto.
- Edición con un subconjunto de comandos Vim.
