# Registro de cambios

Los cambios destacados de cada versión se documentan aquí.

## [0.1.0-alpha.4] - 2026-11-08

- Organiza las notas como archivos Markdown y carpetas normales dentro del cuaderno, con sincronización de cambios externos, recuperación de borradores y papelera restaurable.
- Añade estilos Clásico, Retro y Pop, separados de los temas de color, y plantillas de estudio, idea y requisitos con vista previa.
- Mejora los menús de notas y carpetas, la búsqueda global, la vista previa Markdown, las tareas y el manejo de capturas.
- Recuerda los ajustes de Vim y muestra teclas y combinaciones recientes en el editor.
- Integra una barra propia de Folio en macOS; permite arrastrar la ventana y maximizarla con doble clic en la zona libre.

## [0.1.0-alpha.3] - 2026-11-06

- Publica la primera versión con actualizaciones automáticas de macOS ya operativas.
- Incluye notas de versión en el aviso de actualización de Sparkle.

## [0.1.0-alpha.2] - 2026-11-06

- Añade comprobación de actualizaciones automáticas para macOS con Sparkle.
- Publica paquetes de actualización y notas de versión desde GitHub Actions.

## [0.1.0-alpha.1] - Sin publicar

Primera versión alfa prevista para pruebas públicas.

- Editor local de notas Markdown para macOS.
- Temas Claro, Oscuro, Sepia, Bosque y Gruvbox.
- Selección de carpeta para guardar notas.
- Importación y exportación de archivos Markdown y texto.
- Edición con un subconjunto de comandos Vim.
